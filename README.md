# ⛷️ 滑雪大冒险 (Ski Adventure)

一个精美的无尽跑酷小游戏，灵感来自谷歌小恐龙，但场景换成了雪山滑雪！

## 🎮 在线试玩

直接用浏览器打开 `ski-game.html` 即可游玩，无需安装任何依赖。

## 📋 操作说明

| 按键 | 动作 |
|------|------|
| `↑` / `空格` | 跳跃 |
| `↓` | 蹲下 |
| 触屏 | 点击跳跃，向下滑动蹲下 |

## 🏔️ 关卡系统

游戏共有 **10 个关卡**，难度逐渐提升：

| 关卡 | 场景 | 障碍物 | 特色 |
|------|------|--------|------|
| 1-2 | 明亮白天 | 树木 | 入门阶段 |
| 3-4 | 金色夕阳 | 树木、岩石 | 出现空中障碍（需蹲下） |
| 5-6 | 火红黄昏 | 树木、岩石、雪人 | 速度加快 |
| 7+ | 暴风雪夜 | 全部障碍 | 满天繁星 + 风效 + 最高速 |

## ✨ 画面特色

- 🎿 精细绘制的滑雪者（带物理动画的围巾、护目镜反光、雪板翘起）
- 🌲 多层视差滚动的雪山背景
- ❄️ 80+ 动态雪花粒子系统
- 🐦 飞鸟、云朵、滑雪痕迹等环境细节
- 🌅 随关卡动态变化的天空（白天 → 傍晚 → 黄昏 → 夜晚）

## 🛠️ 技术栈

纯原生 HTML5 Canvas + JavaScript，无任何第三方依赖。

## 📱 兼容性

支持所有现代浏览器（Chrome、Firefox、Safari、Edge），同时支持触屏设备。
